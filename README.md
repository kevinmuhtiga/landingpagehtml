## 🔥 Fitur Utama

- ✅ **Desain Responsif** — Menggunakan Media Queries agar tampil optimal di semua ukuran layar.
- ✅ **CSS Flexbox & Grid** — Layout fleksibel dan modern yang mudah disesuaikan.
- ✅ **Animasi Ringan** — Transisi dan efek interaktif yang memperkaya pengalaman pengguna.
- ✅ **Aksesibilitas & SEO** — Menggunakan elemen semantik HTML5.
- ✅ **Optimasi Kecepatan** — Minim CSS & efisiensi tinggi untuk kecepatan muat maksimal.

---

## 🛠️ Teknologi yang Digunakan

| Teknologi | Deskripsi |
|----------|-----------|
| **HTML5** | Struktur dasar halaman web, elemen semantik untuk SEO & aksesibilitas |
| **CSS3**  | Styling halaman dengan Flexbox, Grid, dan animasi CSS |
| **Media Queries** | Menyusun desain responsif lintas perangkat |

## 🎯 Tujuan Proyek

Meningkatkan keterampilan dasar dalam membangun landing page statis tanpa JavaScript. Template ini cocok untuk:
- Portofolio pribadi
- Promosi produk/jasa
- Halaman awal aplikasi
