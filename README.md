# landingpagehtml
Landing page ini dibangun dengan HTML dan CSS untuk menampilkan desain responsif yang bersih dan profesional. Menggunakan Flexbox dan Grid, halaman ini dapat menyesuaikan diri di berbagai perangkat. Dengan animasi CSS ringan dan struktur HTML semantik, halaman ini cocok untuk portofolio atau promosi produk. Simple, cepat, dan efisien.
